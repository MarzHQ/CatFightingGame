## Decription
I created a cat boxing fighting game, which has an orange cowboy cat and a green alien cat.
These characters were inspired of a ongoing project that I created during my college.
The characters are based on my real life kitties, which inspired me to create this game of them.

In this game you are able to play with another person, as you are able to use the keys on they keyboard.
Player 1 : WAD (movements)+ R, T (attacks)
Player 2 : right, left, up (movements)+ 1, 2 (attacks)

All movements should have different animations, as well as the attacks, and sound effects.
Once you do defeat an opponent a victory image shows, to show that youv'e won, and restarts the game
with a countdown of 3 seconds. Each Player has it's own score and everytime an opponent is defeated 
their score goes up by 1.

For design consideration I would definently add more details onto the characters, such as the orange
cat should have a cowboy hat. This was my first time working with sprite sheets which I learn some
new things which I wish I learned at the beginning when working on them. I also would like to improve more on the sprite sheets animation, and add different attacks on both characters instead of just being a hit, and a punch. My animation sprites I will say it is a bit wonky, they move a bit to much which I would want to definently improve on. 

Another thing I learned was the mixer, which pygame has a library that you can use called mixer. You are able to add sounds and music with this, similar to when exporting images. 

Another future improvement that I could also do what the box collission, I realized that it's not outside of my character but inside which doesn't make sense as much, you will need to get closer to the character in order to hit it, I completely forgot that I had to created a box collission bigger than the character/player.

I also created all the art involed in the game including the background, sprite sheets for both players.
